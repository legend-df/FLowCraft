工具添加指南 / Tool Addition Guide

概述 (Overview)

本文档详细说明了如何在FlowCraft应用程序中添加新的工具。每个工具都遵循一套标准的添加流程，包括枚举定义、UI创建和事件处理。

Overview

This document explains in detail how to add new tools to the FlowCraft application. Each tool follows a standard addition process including enum definition, UI creation, and event handling.

当前工具 / Current Tools

FlowCraft目前包含以下三个工具：

  • Select (选择) - 用于选择和拖拽图元
  • DeleteLine (删除连线) - 用于删除连接线
  • DeleteNode (删除节点) - 用于删除节点

工具添加步骤 / Tool Addition Steps

步骤 1: 定义工具枚举 / Step 1: Define Tool Enum

在 Globe/Enum.h 文件中的 ToolType 枚举中添加新的工具类型：

Add a new tool type to the ToolType enum in Globe/Enum.h:

//工具枚举 enum ToolType { Select, DeleteLine, DeleteNode, // 添加新工具在这里 / Add new tools here NewTool // 示例新工具 / Example new tool };

步骤 2: 准备图标资源 / Step 2: Prepare Icon Resources

为新工具准备图标文件（建议PNG格式）并将其添加到资源文件中。确保图标文件放置在适当的资源目录中，通常是 :/NodeData/icon/ 路径下。

Prepare an icon file (PNG format recommended) for the new tool and add it to the resource files. Ensure the icon is placed in the appropriate resource directory, typically under :/NodeData/icon/ path.

步骤 3: 在主窗口中创建工具按钮 / Step 3: Create Tool Button in Main Window

在 UI/Editor/MainWindow.cpp 文件的构造函数中，添加新的工具按钮创建代码：

In the constructor of UI/Editor/MainWindow.cpp, add code to create the new tool button:

// 创建新工具按钮 / Create new tool button QToolButton* newTool = new QToolButton(); newTool->setIcon(QIcon(":/NodeData/icon/newTool.png")); // 设置图标 ui->toolBar->addWidget(newTool); // 添加到工具栏 // 连接点击事件 / Connect click event connect(newTool, &QToolButton::clicked, [=]() { // 设置自定义光标 / Set custom cursor QPixmap cursorPixmap(":/NodeData/icon/newTool.png"); cursorPixmap = cursorPixmap.scaled(32, 32); QCursor customCursor(cursorPixmap, 0, 0); QApplication::setOverrideCursor(customCursor); // 设置视图工具类型 / Set view tool type view->Tool = NewTool; });

步骤 4: 实现工具功能逻辑 / Step 4: Implement Tool Functionality

在 Graphics/GraphicsView/Graphicsview.cpp 文件中实现新工具的功能逻辑。主要需要修改鼠标事件处理函数：

Implement the new tool's functionality logic in Graphics/GraphicsView/Graphicsview.cpp. You mainly need to modify mouse event handling functions:

// 在 mousePressEvent 中添加 / Add in mousePressEvent void GraphicsView::mousePressEvent(QMouseEvent* event) { if (event->button() == Qt::LeftButton) { IsLeftButtonPress = true; } if (Tool == Select) { setDragMode(QGraphicsView::RubberBandDrag); } else if (Tool == NewTool) // 添加新工具逻辑 / Add new tool logic { // 实现新工具的鼠标按下逻辑 // Implement mouse press logic for new tool handleNewToolPress(event); } // ... 其他工具逻辑 } // 在 mouseMoveEvent 中添加 / Add in mouseMoveEvent void GraphicsView::mouseMoveEvent(QMouseEvent* event) { if (Tool == NewTool && IsLeftButtonPress) { // 实现新工具的鼠标移动逻辑 // Implement mouse move logic for new tool handleNewToolMove(event); } // ... 其他逻辑 }

重要提示 / Important Notes

  • 确保在运行时检查 RuningConfig::IsRuning 状态，某些工具在运行时可能需要被禁用
  • 考虑添加音频反馈，使用 AudioPlayer::Play(AudioType::...)
  • 为用户操作提供适当的提示信息，使用 GraphicsTip::showTips()
  • 遵循现有的代码风格和命名约定
  • Ensure to check RuningConfig::IsRuning status at runtime, some tools may need to be disabled during execution
  • Consider adding audio feedback using AudioPlayer::Play(AudioType::...)
  • Provide appropriate user feedback using GraphicsTip::showTips()
  • Follow existing code style and naming conventions

完整示例 / Complete Example

以下是添加一个"复制节点"工具的完整示例：

// 1. 在 Globe/Enum.h 中添加枚举 enum ToolType { Select, DeleteLine, DeleteNode, CopyNode // 新增复制节点工具 }; // 2. 在 MainWindow.cpp 构造函数中添加按钮 QToolButton* copyNode = new QToolButton(); copyNode->setIcon(QIcon(":/NodeData/icon/copyNode.png")); ui->toolBar->addWidget(copyNode); connect(copyNode, &QToolButton::clicked, [=]() { QPixmap cursorPixmap(":/NodeData/icon/copyNode.png"); cursorPixmap = cursorPixmap.scaled(32, 32); QCursor customCursor(cursorPixmap, 0, 0); QApplication::setOverrideCursor(customCursor); view->Tool = CopyNode; }); // 3. 在 Graphicsview.cpp 中实现功能 void GraphicsView::mousePressEvent(QMouseEvent* event) { // ... 现有代码 ... else if (Tool == CopyNode) { setDragMode(QGraphicsView::NoDrag); QGraphicsItem* item = itemAt(event->pos()); if (item && item->type() == GraphicsItemType::Node) { // 实现节点复制逻辑 Manager->CopyNode(item); AudioPlayer::Play(AudioType::Built); } } }

注意事项 / Warnings

  • 修改枚举时要注意现有代码的兼容性
  • 测试新工具与现有功能的交互
  • 确保资源文件正确包含在项目中
  • 考虑工具的撤销/重做功能
  • Be careful about compatibility with existing code when modifying enums
  • Test the interaction between new tools and existing functionality
  • Ensure resource files are properly included in the project
  • Consider undo/redo functionality for the tool

测试新工具 / Testing New Tools

添加新工具后，请进行以下测试：

  1. 编译并运行应用程序
  2. 验证工具按钮是否正确显示在工具栏中
  3. 测试工具的基本功能
  4. 测试与其他工具的切换
  5. 测试在运行时的行为
  6. 验证光标和视觉反馈

After adding a new tool, perform the following tests:

  1. Compile and run the application
  2. Verify the tool button appears correctly in the toolbar
  3. Test the tool's basic functionality
  4. Test switching between tools
  5. Test behavior during runtime
  6. Verify cursor and visual feedback
